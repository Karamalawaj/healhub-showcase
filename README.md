# HealHub

Portfolio showcase for a multi-clinic healthcare application built with Flutter and Firebase.

## Overview
HealHub is a healthcare application prototype designed to connect patients and doctors across multiple clinics through role-aware workflows and schedule-based appointment management.

## Key Features
- Patient and doctor authentication flows
- Multi-clinic appointment booking
- Appointment lifecycle management
- Doctor-patient communication features
- Digital prescription workflows
- Community and rating features
- Notifications and role-aware user experiences

## Tech Stack
Flutter · Dart · GetX · Firebase Authentication · Cloud Firestore
