# HealHub — Recruiter Summary

HealHub is a Flutter/Firebase healthcare coordination prototype designed around distinct patient and doctor workflows across multiple clinics.

## What it demonstrates
- Role-aware mobile application architecture
- Appointment scheduling and lifecycle management
- Doctor availability configuration
- Prescription workflows
- Community, ratings, and notifications
- Firebase Authentication and Cloud Firestore integration
- GetX-based routing and reactive state management

## Portfolio scope
This public repository is a recruiter-facing showcase. The full application source remains private so credentials, configuration, security rules, and sensitive implementation details are not exposed.
